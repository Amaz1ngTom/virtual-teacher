# 教材课程生成器

## 第一阶段：PDF文本预览

当前实现是完全离线的最小链路：

```text
浏览器选择PDF
  → 上传原始PDF字节到本地FastAPI
  → 校验文件、大小和页码范围
  → pypdf仅读取指定页面
  → 根据文本坐标过滤页边注释
  → 检测文本层
  → 清理独立页码和空白
  → 识别章/节标题并跨页去重
  → 返回逐页文本预览
```

这一阶段不需要Embedding、OCR、PyTorch、LangGraph或语言模型，也不会占用GPU。

### 按书签拆分整本教材

对于带有完整顶层章节书签的电子教材，可以先拆成逐章PDF：

```powershell
python scripts/maintenance/split_pdf_by_bookmarks.py `
  "教材.pdf" `
  "output\pdf\教材-按章"
```

脚本只拆分名称符合“第N章”的顶层书签；附录、后记和索引默认不混入正文章节。
输出目录同时生成 `chapters.json`，记录每章在原PDF中的起止页、页数、文件名和大小。
拆分结果位于 `output/`，不会进入Git。

## 当前限制

- 只处理带文本层且未加密的PDF。
- 无文本或文本少于40字符的页面会被标记并跳过，不自动OCR。
- 一次最多预览50页，文件最大150MB。
- 页边注释使用正文主左边界估计进行过滤，适合当前测试教材，但复杂多栏文档仍需人工检查。
- 公式、表格和图片目前只保留它们在PDF文本层中的文字，不还原视觉结构。
- “按页码快速预览”不落盘；“上传整本PDF”会保存在本机 `data/course-imports` 并按内容指纹去重。

## 真实样本结果

测试文件位于开发机器工作区外，不进入Git。对《机器学习》教材PDF第23至28页的结果：

- 总页数：442；
- 抽样页数：6；
- 有文本层页面：6；
- 跳过页面：0；
- 识别结构：第2章、2.1、2.2、2.2.1、2.2.2、2.2.3、2.2.4和2.3。

## 第二阶段：AI课程蓝图Demo

用户确认正文范围后，可以手动触发一次千问文本模型调用：

```text
已提取的逐页正文
  → 用PDF文件页码包裹每页原文
  → 限制最多20页、24000字
  → 输入目标学习者、课时数和建议时长
  → 千问生成结构化JSON课程蓝图
  → 后端校验课时数、讲稿、题目、选项和全部来源页码
  → 网页展示可编辑草稿
  → 等待人工确认，随后可手动发布
```

课程蓝图包含课程简介、学习目标，以及每个课时的目标、2至3段可直接朗读的讲稿、
一道三选一检查题和对应PDF页码。模型提示词明确禁止使用教材以外的事实；后端还会
拒绝任何超出所选页面的页码引用。页码通过不等同于事实核验，因此草稿始终标记为
`human_review_required`，不能直接进入确定性课程树。

PDF提取预览不调用模型。只有用户点击“生成课程蓝图 Demo”才会调用一次千问；这一
阶段不调用TTS或FLOAT，也不建立向量索引。

## 第三阶段：整本教材导入与逐章生成

正式网页流程支持一次上传整本PDF：

```text
上传整本PDF
  → 用文件内容SHA-256指纹去重并保存在本机data/course-imports
  → 优先读取PDF顶层书签建立章节清单
  → 无书签时扫描正文页首的中英文章标题
  → 再无章标题时尝试顶层编号标题
  → 仍无可靠结构时按每30页建立内容单元
  → 用户点击某章后在本机提取该章正文
  → 按每批最多20页、24000字自动分批
  → 显示预计模型调用次数
  → 用户确认后逐批生成蓝图
  → 合并为一个章节课程草稿
  → 保存到该教材的drafts目录，章节列表标记“已有草稿”
  → 标记跨批次衔接为人工复核项
```

书签识别、正文标题扫描、固定页数分组、章节预览、字符统计和分批规划均不调用模型。每个模型请求保留完整页边界，
不会从一页中间截断；当前一个章节最多160页或8个模型批次。上传相同PDF时复用相同
`import_id`，不会重复保存另一份文件，也不会重复扫描已缓存的新版导入元数据。

没有章节书签并不阻止导入。当前本地结构识别按以下优先级回退：

1. PDF顶层章节书签；
2. 正文页首的“第N章 / Chapter N / 第N部分（篇、单元）”；
3. 至少出现两个不同序号的“1. 标题 / 2. 标题”；
4. 每30页一个“内容单元”。

后两类属于弱结构，网页会明确提醒人工检查起止页。若整份PDF没有可用文字层，系统仍
展示固定页数分组，但会标记“需要OCR”并禁止直接生成课程。语义聚类式章节推断暂不
启用，因为它需要额外模型并且结果不够稳定；后续可作为用户确认后触发的可选增强。

逐章生成是显式操作，不提供默认“一键立即生成整本书”，防止一次意外产生几十次模型
调用。最终产品可以在显示预计调用次数和费用后增加多章任务队列。

章节生成成功后，草稿保存在 `data/course-imports/{import_id}/drafts`。重复生成同一章会
原子覆盖该章旧草稿，不影响其他章节；重新上传同一PDF后仍能看到哪些章节已有草稿。

### 人工校正章节结构

章节列表右上角提供“调整标题和页码”。编辑器一次提交整份章节结构，并检查：

- 编号和顺序没有改变；
- 标题非空且不超过100字；
- 页码位于原PDF范围内；
- 相邻内容单元按页码递增且不重叠；
- 单个内容单元不超过160页。

保存后，识别方式标记为“人工校正”。旧草稿不会被删除；如果标题或页码与生成草稿时
不同，网页会标记“范围已变更，需要重新生成”，后端也会禁止发布这个过期草稿。

### 审核并发布为确定性课程

生成后的课程蓝图可以在网页修改课程名称、简介、学习目标、每课时标题与目标、讲稿、
三选一题目、选项、答案和答案说明。点击“确认审核并发布”时，后端会再次执行结构校验：

- 所有必填文本有效；
- 每题恰好有3个不同选项，答案必须属于选项；
- 所有引用页码仍位于当前章节范围；
- 当前草稿没有因为章节调整而失效。

网页把“教材与章节”和“课程草稿编辑”分成两个工作台，避免长章节列表与讲稿表单混在
同一滚动区域。系统优先根据教材的主要小节数填写默认课时数，并自动排除阅读材料、习题、
小结和参考文献；无法可靠识别结构时才根据页数与文字量估算。课程生成必须保留全部主要
小节，只能压缩讲解内容或合并相邻小节。页面还会展示讲稿实际引用的页码覆盖率；覆盖低于
65%会要求重点人工确认。覆盖率只是遗漏风险提示，并不等价于内容质量评分。

发布过程不调用语言模型、TTS或FLOAT。审核结果会编译为 `guided` 固定课程并保存到
`data/course-imports/{import_id}/published`，重启服务后自动重新注册。发布课程会出现在
教学模式下拉框中；课程的讲稿、检查题、正确答案和反馈均为确定性内容，正常主路径不
调用语言模型。较长课程自动选取2至3个检查点，且最后一节一定保留检查点；学生仍可在
课程中使用“向老师提问”走动态问答支路。

已发布章节会在章节列表标记为“已发布为固定课程”。需要撤回时可点击“下架课程并保留
草稿”：课程会立即从教学模式列表移除，但教材PDF、RAG索引和人工审核草稿都会保留，
修改后可以再次发布。下架同样不会调用语言模型、TTS或FLOAT。

网页左侧的“管理课程”独立汇总全部本地教材下的草稿和发布记录，不依赖当前导入窗口。
课程可以从这里重新打开编辑、下架保留草稿，或彻底删除课程与草稿。彻底删除不会删除
原教材PDF和RAG索引，避免为了清理课程而重复上传、拆章和建立索引。

重新上传同一PDF并点击已有草稿的章节时，网页会直接读取本机草稿继续编辑，不会再次
调用千问。只有过期草稿必须根据新页码范围重新生成。

## 完整课程生产流程

1. 上传整本PDF并确认自动识别的章节范围。
2. 逐章分批生成带页码出处的AI课程蓝图。
3. 在网页人工修改讲稿、题目和答案；引用页码由后端继续校验。
4. 点击审核发布，把蓝图编译为可直接选择的确定性课程树。
5. 预生成TTS和FLOAT视频并进入课程媒体缓存。
6. 教学过程中临时提问再使用RAG检索教材原文并动态回答。

当前已支持本地Embedding和混合检索，用于跨章节检索与课堂临时问答；它们不是
生成小范围课程蓝图的前置条件。见 rag.md。

OCR继续作为按需扩展；在电子PDF流程稳定前不部署OCR模型。
